# Calculator App

A simple command-line calculator that performs basic arithmetic operations.

## Features
- Addition, subtraction, multiplication, and division
- Input validation
- Error handling for invalid operations
- Continuous operation until user exits

## Usage
1. Run the application: `python src/main.py`
2. Enter calculations in the format: `number operator number` (e.g., `5 + 3`)
3. Type "exit" to quit the program

## Example
```
Welcome to the Calculator App!
Enter a calculation (or "exit" to quit): 10 / 2
Result: 5.0
Enter a calculation (or "exit" to quit): 5 + abc

Enter a calculation (or "exit" to quit): exit
